# Разбор настроек владельца по темам

Нужен, если в кабинете поведение вводится одним свободным текстом. Запускается **один раз при сохранении** настроек, а не на каждое сообщение клиента. Результат сохраняется и показывается владельцу: «вот как ассистент понял ваши правила» — с возможностью поправить каждую тему.

Если в кабинете сразу сделать поля по темам Т1–Т16 — этот шаг не нужен.

## Промпт разбора

```
Ты разбираешь инструкции владельца салона красоты для ИИ-администратора. Разложи текст по темам. Ничего не добавляй, не смягчай и не исправляй — переноси слова владельца как есть, можно только убрать повторы.

Темы:
Т1 Обращение и тон
Т2 Длина и форма ответов
Т3 Эмодзи
Т4 Приветствие, имя клиента, прощание
Т5 Цены
Т6 Скидки, акции, сертификаты, абонементы
Т7 Предоплата, отмена, перенос, опоздание, неявка
Т8 Как вести к записи
Т9 Жалобы, переделки, возвраты, споры
Т10 Здоровье
Т11 Дети
Т12 Допродажа
Т13 Когда звать администратора
Т14 Посторонние темы и грубость
Т15 Мастера
Т16 Нерабочее время
Прочее — то, что не подходит ни к одной теме

Правила:
— Одна фраза может попасть в несколько тем, если касается нескольких.
— Тема, о которой владелец ничего не написал, в ответ не попадает.
— Сведения о салоне (цены, адреса, имена, условия) оставляй в той теме, к которой они относятся.
— Если инструкция требует от ассистента сказать, что запись создана, без реальной записи, гарантировать безопасность процедуры для здоровья, попросить данные карты, паспорта или пароли, — перенеси её в "conflicts_with_core" с коротким объяснением. Эти правила ассистент выполнять не будет.

Ответ — только JSON:
{
  "topics": { "Т1": "…", "Т7": "…" },
  "other": "…",
  "conflicts_with_core": [ { "text": "…", "reason": "…" } ]
}

Текст владельца:
{ownerText}
```

## Что делать с результатом

- `topics` → блок «НАСТРОЙКИ САЛОНА»: список ключей идёт в строку «Владелец заполнил темы», тексты — по разделам.
- `other` → раздел «Прочее».
- `conflicts_with_core` → не в промпт, а владельцу в кабинет: «Это правило ассистент выполнять не будет, потому что…».
